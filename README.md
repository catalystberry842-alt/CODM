# Strike Zone

A 3D 5v5 Team Deathmatch shooter that runs in the browser. Built with Three.js.

**Play:** https://catalystberry842-alt.github.io/CODM/ · https://strikezone-game.vercel.app

## Controls
**Phone:** left side to move (push up to sprint), right side to look, red button to fire, scope to aim, arrows to reload, chevron to jump.

**Keyboard & mouse:** WASD move, Shift sprint, mouse look, left click fire, right click aim, R reload, Space jump, Esc pause.

## Features
- Lobby, loadout (assault rifle, SMG, sniper) and settings menus
- AI teammates and enemies with 3 difficulty levels
- Minimap, kill feed, hit markers, kill streaks and end-of-match scoreboard
